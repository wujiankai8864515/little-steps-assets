# 第一次使用资产工坊

告诉 Codex：“用 asset-workbench 打开资产工坊。”

## 先看看已有资产

资产库分为 **模型库、动作库、序列帧库**。每张卡片都有封面，点击后在同一张卡片内预览；点另一张就切换。模型可拖动观察，动作可播放和拖进度，序列帧直接播放已有图片。

同一个角色只显示一张模型卡片，旧的动作组合版、材质修正版收在“版本记录”。动作附带的演示人物留在动作卡片，不占模型库。不同来源的同名动作仍分别保留，方便比较。

查看库存不会改变工作台。需要制作时，点模型卡片的“用于工作台”。

## 三个框，接着做

1. **工作台名称**：每次新建必须填写名字。添加动作继续留在当前工作台，不产生另一个工作台。已有工作台可在顶部改名和切换。
2. **模型**：左侧只展示原始静止外观，可旋转观察。
3. **已选动作**：点“添加动作”，点候选的 ▶ 在本框角色上试播；合适再点“确认加入”。原有动作点行前 ▶ 就播放，移除点 ×。
4. **序列帧**：勾选要制作的动作，在本框调角度和大小。点击“确认构图，生成 N 个动作”后才出帧。完成后本框连续洋葱播放；“下载整套序列帧 · ZIP”可一次取走全部动作。

调整镜头不自动制作。添加动作只更新相关列表与片段，保留相机、筛选和画布。关键操作即时记在本机，稍后同步资产库；关闭后再打开可继续原任务。尚未上传的电脑文件不能凭空恢复。

## 动作不够

在“添加动作”中切换来源或导入 FBX/GLB。点“去 Mixamo 获取”，按步骤准备 FBX → 官网登录、绑骨和下载 → 导回动作库。导入后可以直接在资产卡片播放；使用到具体角色前仍要在工作台试播、确认加入。

## 生成模型

输入描述，或一次上传同一模型的多个视角；可以补图、移除、前后排序，最多 32 张。用图时按图生成，文字仅作备注。有图和描述不代表会另调用付费四视图生成。

描述和参考图列表会保存。点击“查看生成费用”，核对后再“确认生成”。重新打开不会自动提交付费任务，已经提交的继续跟踪原任务。生成结果进入模型库，先看外观，再决定是否加入工作台。

## 2D 多动作验收

同一个模型、同一次构图的 N 个动作统一为一套 2D 动作集。洋葱播放叠影与位置十字用于比较锚点，可以暂停、慢放、拖进度，并调整播放顺序。只改播放顺序，不改原 PNG。

资产库也可在序列帧卡片里查看各动作、打开洋葱播放和下载。不同模型或构图导出的图片是独立资产，不与通用动作混为一个条目。

## 文件和恢复

文件、工作台名称、选用、草稿、原任务与播放顺序保存在绑定资产库。状态显示“已记在本机，等待同步”时，表示服务暂未收到最新草稿，保留浏览器数据后重新连接。

出问题从“制作记录与设置”复制任务给 Codex。迁移时告诉 Codex 目标盘和目录，连同 Skill、资产、封面和数据库一起处理。制作完成、点过预览、选用都不是质量审核结论。

## 模型名字与“没有骨骼”

上传时，选好文件后先为每个模型起名，再点“命名并导入”。生成时，最上方“模型名称”必填。卡片标题旁的铅笔可以改模型名，不会更改工作台名。

看到“需先绑定骨骼”时，在工作台的已选动作框点“先绑定骨骼”：下载上传用 FBX → 打开 Mixamo 上传并按提示标记关节 → 下载 With Skin → 回到本框“导入已绑定的角色”。看完导回预览，再点“确认外观，继续添加动作”。

这一步是给现有外形添加骨骼和蒙皮，不再生成一次外形。工作台会继续使用绑定版本，原始模型仍保留在版本记录里；以后同一角色可继续使用本地动作库。
