# 新人界面与组件选择

更新：2026-10-08。

## 用户目标

第一次使用也能完成「选择模型 → 勾选动作 → 开始 → 自动预览」。页面上的每一个选择都应当服务于眼前的任务。

- 四个入口：我的作品、生成模型、添加动作、导出图片。
- 添加动作只有模型、动作两项输入。默认保留原有动作，已包含的动作显示「模型已有」。
- 生成模型只需描述或参考图片；真实报价与付款确认仍需显示，因为这直接关系到用户花费。
- 导出图片选择模型和动作后直接调整方形画布：旋转、缩放、平移，自动更新同构图的 GIF。默认透明背景、512 像素、24 帧；画质设置可展开。保存使用已预览的原 PNG。
- 添加动作页面直接显示“去 Mixamo 获取新动作”。准备 FBX、打开网站、批量导回集中在同一个三步抽屉，不再藏到资源管理中。网站登录、动作选择和下载在 Mixamo 完成。
- 完成后自动显示结果，手机窄屏自动滚动到预览。制作记录、骨架、贴图等技术详情放在资源管理中。
- 进度有真实数量才显示百分比；否则显示持续处理中。失败保留任务并提供一个继续处理入口。

## 调研与取舍

| 方案 | 官方能力 | 在本项目中的取舍 |
| --- | --- | --- |
| [shadcn/ui](https://ui.shadcn.com/docs) | 可直接编辑源码的组件体系；[官方 MCP](https://ui.shadcn.com/docs/mcp) 可供 AI 搜索和安装组件 | 采用其源码组件组织方式，Select 结构基于官方 Radix 实现改编，保留 MIT 许可。本次没有安装全局 MCP 或迁移整站到 Tailwind |
| [Radix Primitives](https://www.radix-ui.com/primitives/docs/overview/introduction) | 选择器、弹窗、进度、提示等基础交互；键盘导航和焦点管理 | 实际安装 Select、Dialog、Progress、ToggleGroup、Tooltip；统一由本地 CSS 设计变量控制外观 |
| [21st.dev](https://21st.dev) | 多作者组件和主题目录，可复制到 AI 工具；部分拷贝和 AI 生成能力有额度或付费限制 | 作为设计参考，不引入它的生成服务或账号依赖 |
| [Magic UI](https://magicui.design/docs) | 主要面向落地页和营销展示的动效组件 | 作为动效参考；本版使用少量本地 CSS 过渡，不引入大范围背景动画或额外付费模板 |

「AI 能读取组件源码」不等于网站需要调用 AI API。交付后的页面使用本地 React、Radix、Three.js，与现有本地任务服务交互。

## 视觉落地

- 深色导航、浅色工作区，绿色只用于选中和主要操作。
- 操作区与预览区分开，大模型展示、柔和灯光和地面阴影。
- 真实模型缩略图来自本地 Blender，不用示意图片代替模型。
- 卡片、按钮、输入框、字体和间距使用统一样式；按钮具有焦点和选中状态。
- 操作卡片的动作名称已中文化，保留底层原动作名称和 index。
- 支持窄屏布局和减少动态效果的系统偏好。
