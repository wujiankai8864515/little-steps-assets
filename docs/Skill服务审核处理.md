# 本次唯一审核的处理

2026-10-09，用户追加授权一次方案审核。`skill_service_review` 已完成只读审核并结束，未经新命令不再创建或调用审核代理。

| 审核意见 | 决定 | 实施范围 |
|---|---|---|
| 旧来源仅凭数量会误判 | 采纳 | 新输出保存逐片段来源；旧默认策略不明确时保留独立来源，标 unknown |
| frames 取消、部分失败和恢复不清楚 | 采纳 | 每片段状态落盘，保留成功资产；失败列表可读，重试复用成功项；取消进程树与本任务拥有的编码子任务 |
| 入库与版本切换可能产生重复作品 | 采纳 | 文件准备后短 SQLite 事务提交资产、版本关系、job；稳定 productionKey 去重 |
| 精确 ref 与最新版本含义混杂 | 采纳 | inspect/精确下载保留原 ID；preferredRevision 单独提供；动作身份与展示载体分开 |
| 默认全身取景承诺过度 | 采纳 | 明确 default/explicit/confirmedPreset；默认固定取景不承诺整段不裁切；所见即所得要求相同模型哈希 |
| 全局安装与发现不足 | 采纳 | 同步全局 Skill、入口、参考文档与配置；共享命令表；健康检查核对 libraryId 和协议 |
| 许可、历史和质量语义 | 采纳 | history/role 过滤，许可来源 refs；来源质量与目标适配质量分开，未知不自动通过 |
| 独立索引、分支系统、多浏览器、自动全动作取景 | 延后 | 当前数据量可从 SQLite 实时构建目录；历史版本加明确关系已够用，避免引入新服务 |

未采用把原流程整体替换成新的工作流引擎，也不扩展 Mixamo 私有 API 自动化。一次只运行一个捕获浏览器，继续使用现有本地制作和编码队列。
