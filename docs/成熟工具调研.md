# 成熟动作与绑骨工具的选择

调研日期：2026-10-08。官方文档用于功能与格式；用户一手讨论用于经验与故障。没有统一可信的活跃用户统计，不用搜索排名或厂商自称证明“最好”。小型 MCP、抓包下载器和研究项目不作为主流程依赖。

## 简明结论

继续用 Mixamo 补免费动作；AccuRIG + ActorCore 是最接近的替代路线；Auto-Rig Pro 是长期在 Blender 本地积累绑定与重定向能力的成熟候选；Rokoko 是补充动作库/动捕来源。暂时不购买或安装它们，平台首先通用支持它们产出的 FBX/GLB。

| 工具 | 擅长 | 对本项目的价值 | 代价/限制 |
|---|---|---|---|
| Mixamo | 人形自动绑骨 + 现成动作选择 | 已有成功角色和动作，免费起步成本最低 | 网页人工步骤；不能把内部请求当稳定官方 API |
| AccuRIG + ActorCore | 可调整关节与手指的绑骨、配套动作资源 | 绑骨不理想时的优先备选，支持 FBX 角色/动作导出 | 本地软件与网站仍需人工操作；绑骨免费不代表所有动作免费 |
| Auto-Rig Pro | Blender 绑骨、动作重定向、游戏导出 | 对“长期复用动作、积累映射配置”最贴近；有可调映射与手脚修正 | 商业插件、需要学习和适配；不附等同 Mixamo 的免费动作目录 |
| Rokoko Studio / Motion Library | 动捕、动作资源与重定向 | 可补充缺少的表演和动捕片段 | 套餐/动作购买分别核对；库中 FBX 可只有骨架动作、没有模型 |
| DeepMotion Animate 3D | 从表演视频提取动作 | 以后需要专门动作且愿意录制视频时可用 | 不是现成动作库替代；免费有额度/商业用途限制；API 另行咨询，不作为本期依赖 |

## 使用量与经验的证据

- [Auto-Rig Pro 商城](https://superhivemarket.com/products/auto-rig-pro)：当日公开页显示 69,900+ 销售、93,900+ 下载、446 条评分、约十年历史；这是商城数据，不能当活跃用户数。完整版页面价格 $50，含 12 个月支持/更新，后续支持费另列；最终以下单页为准。
- [作者 Remap 文档](https://www.lucky3d.fr/auto-rig-pro/doc/remap_doc.html)：明确源目标骨架、映射、静止姿态与交互修正；预设不是任意目标均可直接套用。经验：存骨架映射与校准，不存“骨骼名字差不多”的判断。
- [AccuRIG 官方功能比较](https://www.reallusion.com/auto-rig/accurig/)与[导出手册](https://manual.reallusion.com/AccuRig-2/2.0/09-add-motions/export.htm)：支持人形、手指、关节调整与目标软件 FBX 导出。免费版和高级 CC 功能不同。
- [Cinema4D 用户一手经验](https://www.reddit.com/r/Cinema4D/comments/17p8f9c/accurig_mixamo_in_cinema_4d/)：有用户认为 AccuRIG 对非标准比例更好调，同时报告崩溃和跨骨架使用困难。旧帖不能证明当前版仍有同样故障，但提醒我们保留原材质与允许人工检查。
- [Gamedev 用户讨论](https://www.reddit.com/r/gamedev/comments/13wyzu8/mixamos_website_is_horrible_any_alternatives/)：常见组合是 AccuRIG 绑骨、Mixamo 动作，而非一家全替代；具体免费数量已过时，不采纳旧数字。
- [Rokoko 动作库手册](https://support.rokoko.com/hc/en-us/articles/4410021327121-Getting-Started-Rokoko-Studio-Motion-Library)：资源以骨架动作 FBX 下载，可搜索、预览、购买/导出；没有网格是正常资源形态。[套餐页](https://www.rokoko.com/pricing)列出免费和付费功能，不能把免费导出等同于全部角色重定向免费。
- [DeepMotion 官方价格与 FAQ](https://www.deepmotion.com/pricing-animate3d)：视频生成、支持 FBX/BVH/GLB，免费用于个人非商业，商业许可与计划相关。页面免费额度表和 FAQ 数值不完全一致，所以不使用旧额度承诺。

## 对本平台的实际影响

1. 文件、资产和动作身份独立于网站；记录来源与许可，资产内网私用，不建设公共原始动作转售库。
2. 同骨架直接合并；新骨架首次用成熟工具或网站完成适配，结果回库并保存适用骨架配置。
3. 缺动作再去网站找；已有动作优先复用。允许人工选动作/关节标记，不为零人工牺牲质量。
4. FBX 纯动作必须支持；纹理、原模型、绑定版、组合版分别保留。
5. 初期提供 Mixamo、ActorCore、Rokoko 的明确入口与导入关联，不虚构它们都有公共 API。
