## 代码与设计经验

本项目实现独立编写。前端布局参考 [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 的设计方法与 [shadcn sidebar](https://ui.shadcn.com/docs/components/base/sidebar) 的导航组织；没有复制这些项目的模板源码。

Three.js、React、Express、fflate、lucide、MCP SDK 等依赖按各包随附 LICENSE 使用，精确安装版本记录于 package-lock.json。

Lux3D 通过已安装的官方私有 Python 运行时调用，没有复制凭据或修改插件缓存。Blender 为本机已安装程序。

已有 Motion Studio 的来源保留、时间采样、统一取景和分页图集经验被采用；新后台独立实现，没有复制其昂贵的逐三角面分析功能。小型下载器/研究仓库只用于识别风险，没有作为平台核心依赖。
