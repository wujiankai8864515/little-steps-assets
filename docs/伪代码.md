# 资产工坊伪代码

```text
startup:
  open SQLite, migrate schema
  load paths from local settings; detect Blender and installed Lux3D runtime
  mark unfinished local RUNNING jobs INTERRUPTED
  remote tasks with taskId -> queue polling original task
  remotely SUBMITTING without taskId -> NEEDS_INPUT(outcome unknown)
  serve frontend and API on loopback
  run one local job at a time

import(files, name, source):
  validate file count/size/extensions and sidecar paths
  archive source bytes under content hash; never overwrite originals
  create IMPORT job -> QUEUED
  Blender imports GLB/GLTF/FBX/OBJ into isolated empty scene
  collect mesh, material, skeleton/rest, clips
  produce self-contained preview GLB and metadata
  create asset + motion records + provenance links in one transaction
  job -> SUCCEEDED with resulting asset ID

compose(modelId, motionIds, options):
  persist job with input IDs and exact settings
  load target from immutable working copy
  for each selected motion:
    if exact compatible skeleton/rest:
      assign copied source action on target without changing target geometry
    else if supported semantic mapping AND compatible reference pose:
      sample source bone rotation deltas parent-first
      apply deltas to target reference rotations, preserve target bone lengths
      scale root displacement, bake named target action
    else:
      save NEEDS_INPUT with concrete missing mapping/rest-pose problem
      return without publishing partial final asset
    record completed clips count
  export selected named actions into one GLB, images embedded
  inspect artifact metadata; register new child asset; keep source untouched

prepare_mixamo(modelId):
  duplicate import; choose rest pose; keep only mesh/armature
  export binary FBX without animations or leaf bones
  save upload asset and concise marker/download instructions
  user completes site steps and drops downloaded FBX back into import
  follow normal compose pipeline

generate(request):
  provider = providers[request.provider]
  validate supported capability, source images, options
  quote = provider.quote(request)              # read-only remote pricing
  save quote bound to request hash/account/region/expiry
  frontend shows price and explicit submit action
  on authorized submit:
    atomically claim quote; reject reused/expired/changed request
    persist SUBMITTING intent before dispatch
    taskId = provider.submit_once(request)
    persist taskId immediately
    poll(taskId) and save actual status
    download outputs into private work directory
    import output into asset library
  if submission outcome unknown: NEEDS_INPUT, no automatic re-submit

render_sequence(modelId, clipName, settings):
  open isolated Blender scene with source model
  choose actual clip; reject unknown clip
  sample all intended times to determine one framing box
  fix orthographic camera and consistent anchor; transparent background
  for every sample time:
    render RGBA PNG; persist rendered/total
  package frames, atlases, timestamps, camera, clip/source references, preview
  register sprites asset linked to model and selected clip

codex_tool(action, arguments):
  call same localhost API as frontend
  return asset/job IDs and actual state
  if needs_input: return concrete next action
  never invent website completion, animation IDs or task percentages

frontend:
  use same assets/jobs API
  poll lightweight job state while visible
  button '复制给 Codex' copies task ID and readable request
  technical settings collapsed by default
  loading/empty/failure states each explain what user can do next
```
